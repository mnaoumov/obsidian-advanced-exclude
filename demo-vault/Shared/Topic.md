# Topic

A normal, visible note that stays in the vault. It is here so you can watch a **backlink disappear** when the note that links to it gets excluded.

Before you exclude anything, open the **Backlinks** pane for this note (right-click its tab -> **Backlinks for the current file**, or the command **Backlinks: Show backlinks**). You should see a backlink from [Archive/Old note](<../Archive/Old note.md>).

After you exclude the `Archive/` folder (see [01 Exclude a folder](<../01 Exclude a folder.md>)), that backlink is gone - Advanced Exclude makes Obsidian behave as if `Archive/Old note` does not exist.
