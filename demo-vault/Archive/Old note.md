An archived note used as an **exclusion target** by [[01 Exclude a folder]].

It links to [[Shared/Topic]] so that, before you exclude it, `Shared/Topic` shows a
backlink from this note. Once `Archive/` is excluded, this file vanishes from the
Files pane, from search, from the graph, and its backlink to `Topic` disappears too.
