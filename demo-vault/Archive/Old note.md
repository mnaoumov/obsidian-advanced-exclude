# Old note

An archived note used as an **exclusion target** by [01 Exclude a folder](<../01 Exclude a folder.md>).

It links to [Shared/Topic](<../Shared/Topic.md>) so that, before you exclude it, `Shared/Topic` shows a backlink from this note. Once `Archive/` is excluded, this file vanishes from the Files pane, from search, from the graph, and its backlink to `Topic` disappears too.
